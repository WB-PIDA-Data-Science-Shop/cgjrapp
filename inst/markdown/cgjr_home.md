Welcome to the GOVCGJR Benchmarking Dashboard!

The GOVCGJR Benchmarking Dashboard provides a standard quantitative methodology to summarize information from a large set of country-level institutional indicators, organized around the institutional analysis of the Country Growth and Jobs Report (CGJR).

For full details about the methodology behind the GOVCGJR Benchmarking, please find the Methodological paper in the Methodology & User Guide tab. Users of this resource should cite this paper. Publications using the GOVCGJR data should include a citation of the GOVCGJR Dashboard as well as the original source(s) of the data used. Citation information for each component dataset is also included in the Methodology & User Guide page.

### How to use this dashboard

This dashboard enables its users to interact with the GOVCGJR benchmarking through the following tabs:

- The **Country Selection** tab is where you choose one or more base countries and a group of comparator countries, the benchmarking thresholds, and the year range for the dynamic view. Click **Apply selection** to update every other tab. Regions and income groups can be picked as shortcuts for their member countries.
- The **Benchmarking** tab shows how one country compares to another group of countries in terms of closeness to frontier for each relevant indicator and institutional cluster. It works best with a relatively large group of comparator countries.
- The **Data** tab provides interactive tables containing the closeness to frontier data and the raw indicator values for the current selection, together with the indicator catalogue. It also allows users to download the data in different formats.
- The **AI Report** tab drafts the governance chapter for the base country (the whole chapter, one cluster or one section), following the CGJR guidance note and using the dashboard's own figures and charts. It can be downloaded as a Word document. Its **Chat** answers questions about the guidance and the current selection. Every answer cites its sources, and the citations are checked automatically.
- The **Methodology & User Guide** tab includes metadata on the indicators, country groups and methods used in the analysis.
- The **Terms of Use and Disclaimers** tab provides more information about the terms of use and disclaimers, as well as citation information.
- The **FAQ** tab shows and answers the most frequently asked questions about GOVCGJR.
- The **Contact Us** tab allows users to directly contact the GOVCGJR team.
- The **Source Code** tab takes users to our GitHub repository where they can access our source code.
